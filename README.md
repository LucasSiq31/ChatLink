O **ChatLink** é uma plataforma de mensagens instantâneas simples e eficiente, focada em proporcionar uma experiência de conversa fluida e em tempo real.

---

### 🚀 Como Funciona

* **Conectividade:** Envie e receba mensagens dos seus amigos instantaneamente.
* **Customização:** Escolha seu nome de usuário e uma cor exclusiva para identificar suas mensagens no chat. 🟡
* **Modo Noturno:** Interface adaptável! Clique no botão de **Lua** 🌛 para alternar para o modo escuro.
* **Limpar Histórico:** Clique na **Varinha Mágica** ✨ para limpar todas as mensagens da sua tela local.
* **Multiplataforma:** Site totalmente responsivo, otimizado para computadores, tablets e celulares. 📱💻

> [!IMPORTANT]
> **Aviso de Sessão:** Este projeto utiliza comunicação em tempo real, mas não possui persistência em banco de dados. Ao pressionar **F5** ou recarregar a página, o histórico da conversa será perdido.

### 🏗️ Objetivo do Projeto

Este chat foi desenvolvido como uma atividade prática para aplicar conceitos de **WebSockets** utilizando a biblioteca **Socket.io**, garantindo que a troca de dados entre cliente e servidor ocorra sem a necessidade de recarregar a página.

## 🔰Como inicializar o projeto

- Faça o download do arquivo pelo github e abra a pasta no terminal.

- Instalar o node pelo link oficial 

- Você pode verificar se o node ja está instalado com o comando no terminal; <br>
``` 
npm -v 
```

- Executar o seguinte comando no terminal para instalar os node-modules:
``` 
npm install json-server express 
``` 

- Executar o seguinte comando no terminal para instalar o socket.io
```
npm install socket.io express
```

- Iniciar o programa com o comando:
``` 
node server.js
```
